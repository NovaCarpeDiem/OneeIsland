## ✨ Features

### 🐾 Onee - The Living Desktop Companion
- **Interactive Physics & Reactions:** Pets, pokes, sleep cycles, and cursor eye tracking.
- **Audio Synchronization:** Dances and bobs rhythmically to currently playing music with custom DJ headphones.
- **Mini Avatar Bubble Mode:** Right-click to detach Onee into an interactive floating desktop bubble anywhere on your screen.

### 🎵 Adaptive Glassmorphic Media Player
- **Universal SMTC Integration:** Works natively with Spotify, Chrome, Edge, Apple Music, and Windows Media Player.
- **Live Karaoke Lyrics:** Real-time synchronized lyrics line with full-screen karaoke overlay.
- **Dynamic Color Aura:** Extracts album artwork colors in real-time to illuminate the island with fluid neon glow.
- **Hardware Seek & Volume:** Ultra-responsive seek slider and mouse-wheel volume control on top of the pill.

### ⚡ Built-in Productivity Suite
- **Spotlight Search & Calculator:** Instant launcher and math calculation (`Alt + Space`).
- **File Tray & Clipboard:** Drag-and-drop file holding shelf and automatic clipboard history.
- **Live Hardware Dashboard:** Real-time CPU, RAM, battery charging morph animation, and network status.
- **Pomodoro Timer:** Gamified focus timer with visual rings and sound notifications.
- **Quick Screen Snipping:** Region snipping and full-screen capture saved directly to clipboard & tray.

## 🚀 Quick Start

### Prerequisites
- Windows 10 (19041+) or Windows 11
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download)

### Build & Run from Source
```bash
# Clone the repository
git clone https://github.com/NovaCarpeDiem/OneeIsland.git
cd OneeIsland

# Build Release binary
dotnet build -c Release

# Run
dotnet run -c Release
```

Or simply run `Baslat.bat` to launch the application.
