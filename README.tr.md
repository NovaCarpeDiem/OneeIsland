## ✨ Öne Çıkan Özellikler

### 🐾 Onee — Yaşayan 3D Masaüstü Dostu
* **3D Etkileşimli Tepkiler:** Fizik tabanlı tepkiler, sevme, dürtme, uyku döngüleri ve fare imlecini takip eden gözler.
* **Müzik Senkronizasyonu:** Çalan şarkının ritmine göre özel DJ kulaklıklarıyla dans eder ve kafa sallar.
* **Bağımsız Mini Maskot Modu:** Adaya veya Onee'ye sağ tıklayarak onu adadan ayırabilir, masaüstünün herhangi bir köşesinde süzülen sevimli bir küre olarak gezdirebilirsiniz.

### 🎵 Adaptif Cam (Glassmorphic) Medya Oynatıcı
* **Evrensel Medya Desteği:** Spotify, YouTube, Chrome, Edge, Apple Music ve Windows Medya Oynatıcı ile doğrudan entegre çalışır.
* **Dinamik Renk Aurası:** Çalan şarkının albüm kapağındaki ana renkleri gerçek zamanlı analiz ederek adayı şarkının tonunda neon bir ışıkla aydınlatır.
* **Canlı Karaoke Şarkı Sözleri:** Gerçek zamanlı şarkı sözü akışı ve tam ekran karaoke modu.
* **Hızlı Ses & İlerleme:** Adanın üst çerçevesinde fare tekerleğiyle ses kontrolü ve akıcı şarkı sarma çubuğu.

  <img src="docs/island_expanded.png" width="90%" alt="Genişletilmiş Medya Adası" />

### ⚡ Dahili Verimlilik Araçları
* **Spotlight Arama & Hesap Makinesi (`Alt + Space`):** Hızlı uygulama başlatıcı, web kısayolları ve anlık matematik hesaplayıcı.
* **Bırakma Rafı & Pano Geçmişi:** Sürükle-bırak dosya rafı ve otomatik pano kopyalama geçmişi.
* **Canlı Donanım Monitörü:** Gerçek zamanlı CPU, RAM, şarj olma animasyonu ve ağ trafiği durumu.
* **Pomodoro Odaklanma Sayacı:** Ses efektli ve görsel halkalı oyunlaştırılmış odak seansları.
* **Akıllı Ekran Kırpıcı:** Seçilen bölgeyi veya tam ekranı anında kırpıp panoya kopyalama.

## ⌨️ Kontroller ve Kısayollar

| Eylem | Hareket / Kısayol | Açıklama |
| :--- | :--- | :--- |
| **Adayı Genişlet** | Adaya `Sol Tık` | Medya, araçlar ve sistem panelini açar |
| **Adayı Küçült** | Dışarıya tıkla / `▲` | Kompakt ada hapına geri döner |
| **Mini Maskot Modu** | Adaya / Onee'ye `Sağ Tık` | Onee'yi bağımsız süzülen masaüstü küresine dönüştürür |
| **Sesi Ayarla** | Ada üzerinde `Fare Tekerleği` | Parlayan çerçeve göstergesiyle sistem sesini değiştirir |
| **Spotlight Başlatıcı** | `Alt + Space` / Arama simgesi | Hızlı arama ve hesap makinesini açar |
| **Adanın Yerini Değiştir** | Adayı `Tıkla ve Sürükle` | Adayı ekranın üst kenarında sağa/sola taşır |

## 🚀 Kurulum ve Çalıştırma

### Gereksinimler
* **Windows 10 (Derleme 19041+)** veya **Windows 11**
* [.NET 10 Masaüstü Çalışma Zamanı (Desktop Runtime)](https://dotnet.microsoft.com/download)
* WebView2 Runtime *(Windows 11'de varsayılan olarak yüklüdür)*

### Kaynak Koddan Çalıştırma
```bash
# Repoyu bilgisayarınıza klonlayın
git clone https://github.com/NovaCarpeDiem/OneeIsland.git
cd OneeIsland

# Release olarak derleyin
dotnet build -c Release

# Uygulamayı başlatın
dotnet run -c Release
```

*Veya doğrudan proje klasöründeki `Baslat.bat` dosyasına çift tıklayabilirsiniz!*
